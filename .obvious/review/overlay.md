# Code Review Overlay — matthew-gerstman/blog

This overlay supplements the Autobuild code-review skill with repo-specific conventions.
Apply these rules on top of the general skill guidance.

---

## Stack Summary

- **React 18** + **TypeScript 5.3** (strict mode)
- **Vite 5** (build tool, dev server on port 3001)
- **React Router 6** (client-side routing)
- **CSS Modules** (all component styles)
- **Vitest 1.3** + Testing Library (infra present; no app tests in `src/` yet)
- **ESLint 9** flat config (`eslint.config.js`) + **Prettier 3** (`.prettierrc`)
- **Husky** + **lint-staged** (pre-commit hooks)
- Deployed to **GitHub Pages** via `gh-pages`

---

## Lint & Formatting — Do Not Duplicate

ESLint and Prettier run automatically on pre-commit (Husky + lint-staged) and in CI.
**Do not flag style or formatting issues in review** — they are enforced mechanically.

To verify locally:
```bash
npm run lint          # ESLint check
npm run lint:fix      # Auto-fix ESLint issues
npm run format        # Prettier format
npm run format:check  # Prettier check
```

## TypeScript

- Strict mode is enabled — no `any`, no `as` at trust boundaries
- Explicit return types on exported functions
- Content types live in `src/data/types/` — extend there, don't inline
- `src/types/` for shared non-data types

---

## React Patterns

- Components live in `src/components/` — one `.tsx` + one `.module.css` per component
- Pages live in `src/pages/` — one `.tsx` per page (no module CSS unless complex)
- Custom hooks in `src/hooks/` — `use` prefix, single responsibility
- Utility functions in `src/utils/` — pure, named, tested when possible
- **No `useEffect` for derived state** — compute during render or lift to parent
- **No global state library** — hooks + props only
- The 8-line rule: if a JSX callback or branch body exceeds 8 lines, extract a named function

---

## CSS Modules

- **CSS Modules only** — no Tailwind, no styled-components, no inline styles
- Import pattern: `import styles from './Component.module.css'`
- Access: `className={styles.myClass}`
- camelCase class names (Vite config enforces this)
- Global styles and CSS variables live in `src/styles/global.css`
- Theme colors use CSS variables: `--color-primary`, `[data-theme="dark"]`, etc.
- Reject any PR that introduces inline style objects or non-Module CSS imports

---

## Routing (React Router 6)

- All routes are defined in `src/App.tsx` inside `<Routes>`
- Use `<Navigate>` for redirects — not imperative `navigate()` at the top level
- Legacy URL redirects: `/tech/*` → `/writing/*` (TechRedirect), `/:slug` catch-all (BlogPostRedirect)
- Do not add new catch-all routes without reviewing existing redirect logic

---

## Content Data

- Blog posts: `src/data/posts.ts` — HTML strings, sequential `id`, `wordCount` auto-calculated
- Projects: `src/data/projects.ts` — unique string `id`
- Talks: `src/data/talks.ts`
- Resume: `src/data/resume.ts`
- **Word counts** are computed at build time by `scripts/calculate-wordcounts.js` (runs via `prebuild` hook)
- Do not manually set `wordCount` unless the post has empty content (external link)

---

## Images

- Original images: `public/images/blog/`
- Optimized images: `public/images/optimized/` (generated by `scripts/optimize-images.js`)
- Always use `<OptimizedImage>` component, not bare `<img>` tags
- Run `npm run optimize-images` after adding new images

---

## GitHub Pages Specifics

- `vite.config.js` copies `index.html` → `404.html` for SPA routing on GitHub Pages
- `index.html` includes a redirect handler script — do not remove it
- `public/CNAME` sets the custom domain — do not delete

## Testing

- Vitest + Testing Library is configured and ready
- Test files: `*.test.tsx` / `*.test.ts` alongside source files
- No app tests exist in `src/` currently — new utility/pure functions should include unit tests
- Run: `npm test`

## Common Review Signals

| Signal | Action |
|---|---|------|
| Inline styles (`style={{...}}`) | Reject — use CSS Modules |
| Non-module CSS import | Reject — all styles via `.module.css` |
| `any` type | Reject — use `unknown` + type guard |
| `useEffect` for derived state | Reject — derive during render |
| Missing `wordCount` reset after content edit | Remind — runs at build, but verify |
| New images without OptimizedImage | Reject |
| Hardcoded color/theme values | Reject — use CSS variables |
| New routes added without checking redirects | Flag for review |
